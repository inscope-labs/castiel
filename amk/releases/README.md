# Releases

Source of the release process. The release artifact is generated by `amk/scripts/build_release.py`; nothing under `dist/` is committed.

- `manifest.schema.json` — schema of `release/MANIFEST.json` in the artifact.
- `provenance/` — one record per published release (TODO).

Integrity: `release/SHA256SUMS` lists every file; `release/MANIFEST.json` records version, source commit and generator hashes. Checksums prove integrity only. Authenticity comes from the detached signature `release/SHA256SUMS.sig` and the build-provenance attestation produced by the release workflow.
